案件處理效率指標

  • 1

    緊醫處理流程依受理方式拆成兩張表新增

    原本只有一條時間軸，從「完成通報」一路畫到「實際出勤」，總反應時間 2.5 小時； 但電話受理的案件不會出勤，這個時間對它們並不成立。V4 改為兩個獨立的流程區塊。

    • ① 電話（電話或平台受理）：完成通報 → 完成派案 → 完成受理方式（電話諮詢結案），占 61.7%（電話處置率）
    • ② 電話＋出勤：在上述流程後再延伸到「實際出勤」，占 38.3%（出勤處置率），總反應時間 2.5 小時
    • 電話路徑另列一個總反應時間 1.0 小時（派案 0.3 ＋ 首次專業評估 0.7），此為推算值，詳見本版「待確認事項」

本版待確認事項

以下五點需要需求端回覆後才能定案

  1. 中風險／低風險個案處理時間的公式。 官方 28 項指標清單中，「中風險個案處理時間」與「低風險個案處理時間」的公式文字 都寫成「緊醫高風險個案完成受理 OR 優化計畫完成首次訪視時間 − 高風險個案通報時間」， 與高風險那條完全相同。儀表板目前使用的是修正後的中／低風險文字；若三條確實都以高風險為基準，請告知改回。
  2. 「緊醫電話受理總反應時間」是推算值。 官方清單只有「緊醫出勤總反應時間」，沿用它會讓電話案件被記成含出勤準備的 2.5 小時， 因此拆表時新增了電話路徑的 1.0 小時（0.3 ＋ 0.7）。 請決定：保留（標示為推算值）／改名（例如「緊醫電話處置完成時間」）／移除。
  3. 院內追蹤「以年計算」的作法。 「醫院內控指標(SNQ) › 院內追蹤與再住院指標」的定義文字目前寫「在Ｘ年中每年均穩定…」。 是要（a）把「Ｘ年」換成實際統計年度、（b）加一個年度選擇器，還是（c）改變計算基準本身？
  4. 「醫師後台＋緊醫通報（補填已處理完案件）」的範圍。 看起來屬於醫師後台的功能而非本儀表板。是要在醫師後台實作，還是儀表板上也要有對應呈現？
  5. 「最新年分在上」是否也套用到同期比較。 V4 只反轉了會議點名的年度結案率趨勢；同一個指揮儀表板的「同期比較 › 通報案件風險分佈」 仍是 2024 在上、2026 在下，兩張圖的年份方向相反。要一起改嗎？

    單檔大小由 2.7 MB 壓到 791 KB效能

    主因是院徽：原圖為 2047×2047 px 的 PNG（1.55 MB，內嵌進檔案後占 2.07 MB），但畫面上只顯示約 55 px。 V3 改為 192×192 px 的無損 WebP（37 KB，內嵌後 49.7 KB，足夠 3 倍高解析螢幕），畫面上看不出差異； 整份檔案縮小約 71%，在行動網路下開啟明顯變快。

    補充：先前曾建議改成 SVG，實際比對後發現院徽是全彩細節圖（金色漸層外環、中英文書法字、雙蛇杖等）， 描繪成 SVG 反而會更大且失真，因此改用 WebP。
