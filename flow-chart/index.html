FlowScript 流程圖原型

用一套極簡的文字語法描述流程，即時畫成流程圖。
左側編輯、右側預覽；產生的檢視連結可直接分享給他人唯讀瀏覽。

編輯 Edit → 左側輸入語法、右側即時預覽，可匯出 SVG / PNG，或複製檢視連結。 檢視 View → 依網址 query 的內容呈現唯讀流程圖，適合分享給客戶或同事。

節點形狀

寫法形狀用途
A(文字)圓角方形一般流程步驟
B{文字}菱形判斷、流程分流
C[文字]正方形某步驟的補充說明（只連一條線時會自動放到側邊）

連接線

寫法樣式
A --> B單向實線箭頭
A -.-> B單向虛線箭頭
A --- B實線連接線（無箭頭）
A -.- B虛線連接線（無箭頭）
