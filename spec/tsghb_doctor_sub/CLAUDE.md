# 三軍總醫院北投分院 — 精神醫療快速應變平台｜醫師次專科欄位（編輯資料頁）原型

帳號資料新增**次專科**欄位（多選下拉）。同一個欄位出現在兩個地方：通報前臺的「編輯帳號」與後臺的「基本資料」，
兩頁改的是同一個帳號的同一份資料。其他欄位、Header、Footer 都是既有畫面，原型只照設計稿放外觀。

設計稿在 `design/`，每張圖左邊是手機（375 寬）、右邊是電腦（1920 寬），都是 2 倍圖。

---

## 1. 檔案結構

```
spec/tsghb_doctor_sub/
├─ CLAUDE.md             本文件
├─ index.html            切換瀏覽頁：用 iframe 切換「通報前臺／後臺」與「電腦／手機」寬度
├─ front/index.html      通報前臺 — 編輯帳號
├─ back/index.html       後臺 — 基本資料
├─ assets/               兩頁共用
│  ├─ form.css           設計 token、表單欄位、次專科下拉（.ss-*）的樣式
│  ├─ form.js            次專科下拉、市內電話區碼、簽章圖片預覽、儲存
│  └─ img/               logo-tsghb.png（院徽）、hospital-bg.png（前臺手機版底部的醫院淡色背景）
└─ design/               設計稿，不被頁面引用
   ├─ 通報前臺編輯資料頁.png
   ├─ 後臺編輯資料頁.png
   └─ 補充資料.png        次專科選項清單、色塊顏色與下拉的參考樣式
```

**沒有 build 流程**，純 HTML＋CSS＋原生 JS（不走 dc-runtime）。直接開 `index.html` 即可，`file://` 也能運作。
字型用 Google Fonts 的 Noto Sans TC；兩張圖是從 `tsghb-quick-report/assets/img/` 複製過來的。

- 頁面外框（Header、標題列、側邊選單、Footer）寫在各頁自己的 `<style>`，class 前綴前臺 `fr-`、後臺 `bk-`。
- **表單欄位的 HTML 兩頁各有一份、內容相同**（`form.js` 靠相同的 `id` 找欄位）。改欄位時 `front/` 與 `back/` 要一起改。

## 2. 次專科欄位

### 2.1 位置

放在「電子信箱」與「簽章圖片」之間，前臺、後臺、電腦、手機都一樣。
（四個畫面的設計稿裡只有前臺手機稿畫了這個欄位，其餘三個畫面比照。）

### 2.2 選項

選項與顏色定義在 `form.js` 的 `SUB_SPECIALTIES`，**只有這一處**；色塊與已選標籤的底色都讀它的 `color`。

| id | 名稱 | 類型 | 色塊顏色 |
| --- | --- | --- | --- |
| `child` | 兒童青少年精神科 | 群組標籤 | `#12ACAC` |
| `addiction` | 藥酒癮精神科 | 群組標籤 | `#12ACAC` |
| `geriatric` | 老人精神科 | 群組標籤 | `#12ACAC` |
| `community` | 社區精神科 | 群組標籤 | `#12ACAC` |
| `forensic` | 司法精神科 | 群組標籤 | `#12ACAC` |

`id` 是原型自己取的，正式的代碼以後端為準。

### 2.3 元件

依 `design/補充資料.png` 的參考樣式：一個控制項（顯示已選的標籤）加一個面板（搜尋框＋選項清單）。

| 部位 | 樣式 |
| --- | --- |
| 控制項 | 與其他輸入框同高、同框線；沒選時顯示灰字「請選擇」；右側箭頭，展開時朝上 |
| 已選標籤 | 底色＝該選項的色塊顏色、白字、tag 圖示＋名稱＋「×」；放不下時換行，控制項跟著長高 |
| 搜尋框 | placeholder「搜尋」，右側放大鏡（`--teal-300`）與一條分隔線 |
| 選項列 | 高 36、圓角 4：**20×20 色塊＋名稱，色塊後面不放圖示** |
| 選項狀態 | 未選中：白底｜hover：`--ss-hover`（`--teal-50`）｜已選中：`--ss-selected`（`--teal-100`） |

- 參考樣式是綠色主題的系統，已選中／hover 用的是 `green-100`／`green-50`；這個平台的主題色是 teal，取同一階的 token。要改只改 `form.css` 的 `--ss-selected`、`--ss-hover`。
- 「去掉色塊後面的 icon」指的是選項列；已選標籤上的 tag 圖示照參考樣式保留。

行為：

- 可複選，點選項切換選中／取消，**面板不會關**；點標籤上的「×」取消該項，面板維持原本的開合。
- 搜尋是名稱的部分比對；沒有符合的顯示「查無符合的次專科」。每次打開面板搜尋字串都清空。
- 已選標籤照選項清單的順序排，不照點選的先後。
- 面板預設往下開；下方放不下、上方又比較寬時往上開（參考樣式是往上開的樣子）。
- 點面板以外的地方、按 `Esc`、`Tab` 離開都會關閉。
- 鍵盤：控制項上按 `Enter`／空白鍵／`↓` 打開；`↑`／`↓` 移動（到底會繞回），`Enter` 切換目前那一列。
  有打字時先停在第一個符合的選項，直接按 `Enter` 就能選。鍵盤移到的列只加外框（`.is-active`），不改底色。
- 觸控裝置（`pointer: fine` 不成立）打開面板時不自動進搜尋框，免得螢幕鍵盤把選項蓋住。

## 3. 版面

尺寸都是從設計稿量出來的。兩頁的基礎樣式是手機版，電腦版在 `min-width:1024px`。

### 3.1 通報前臺 — 編輯帳號（`front/`）

| | 手機 | 電腦（≥1024） |
| --- | --- | --- |
| Header（白底） | 高 56，院徽 40、平台名稱 16px、右側漢堡按鈕 | 高 92，院徽 60、平台名稱 20px、右側使用者名稱 |
| 標題列（`--teal-300`） | 高 45，「編輯帳號」20px | 高 72，24px |

| 頁面底色 | `#F8F8F8`，≤600px 底部有 `hospital-bg.png` | `--grey-50` |
| 輸入框高 | 32（≤600px） | 34 |

### 3.2 後臺 — 基本資料（`back/`）

| | 手機 | 電腦（≥1024） |
| --- | --- | --- |
| Header（`--bk-brand` `#0CB9E4`） | 高 54，院徽膠囊、通知、漢堡按鈕 | 高 58，另有主選單與使用者膠囊 |

## 4. 表單行為與資料

- **必填只有姓名**（去掉頭尾空白後不能是空的），沒填時欄位紅框＋「請輸入姓名」。其他欄位原型不驗格式。次專科非必填、不限選幾個。
- 「儲存」成功後顯示「已儲存」，並把資料存進 `sessionStorage`（鍵 `tsghb-doctor-sub:profile`）。
  **前臺與後臺讀寫同一份**：在一頁存檔後開另一頁會看到同樣的內容，Header 上的使用者名稱也跟著姓名換；關掉分頁就清空。
- 預帶的帳號在 `form.js` 的 `DEFAULT_PROFILE`，是虛構資料（王大明）。
- 簽章圖片只收 `image/png`，其他格式顯示「檔案格式須為 png」；選了之後在框裡預覽，右上角「×」移除。只做本機預覽，不存。
- 市內電話區碼的清單在 `form.js` 的 `AREA_CODES`。
- **靜態、沒有動作的部分**：兩頁 Header 上的所有按鈕、前臺的「返回」、後臺的「修改密碼」（手機的下拉選了會跳回基本資料）與 Footer 文字。

## 5. 切換瀏覽頁（`index.html`）

上方一列切換鈕，下方用 iframe 顯示頁面：「通報前臺／後臺」換頁，「電腦／手機」換寬度（手機是固定 375 寬的框），「開新分頁」直接開目前那一頁。

- 狀態記在網址 `#`：`#front`、`#back`、`#front/mobile`、`#back/mobile`，可以直接分享連結。
- 只切寬度時不會重新載入 iframe，頁面上填到一半的內容會留著。
- 視窗寬度 ≤700px 時不顯示「電腦／手機」，iframe 直接佔滿。
- iframe 的路徑寫到 `index.html`（`./front/index.html`），本機用 `file://` 開才載得進來。

## 6. 與設計稿不同、或設計稿沒有定的地方

給了正式規則就改掉：

- **前臺手機稿的文字是舊版**：它寫「室內電話」、姓名沒有必填星號、輸入框沒有 placeholder。這幾處以另外三個畫面為準（「市內電話」、姓名必填、有 placeholder），手機稿只取版面與次專科的位置。
- **後臺 Header 的主選單**：設計稿截的是心衛中心主管的選單（案件查詢/新增通報、平台使用者列表、報表匯出）。
  這份原型的帳號是醫師，換成醫師入口頁的三個功能（我的案件、案件查詢、管理儀錶板），只是示意。
- **次專科是不是只有醫師帳號看得到**：設計稿沒有寫，原型一律顯示。
- 沒選次專科時的「請選擇」、選項狀態色換成 teal、面板的開啟方向、鍵盤操作、觸控時不自動進搜尋框，都是原型自己定的（見 2.3）。

## 7. 修改須知

- 改選項或顏色：只改 `form.js` 的 `SUB_SPECIALTIES`，並同步本文件 2.2 的表。
- 改欄位：`front/index.html`、`back/index.html` 兩份表單一起改，欄位 `id` 不要改名。
- 顏色用 `form.css` `:root` 的設計 token；token 沒有的（`--bk-brand`、`--fr-page`）定義在該頁 `<style>` 的開頭。
- 這個 repo 是公開的：`DEFAULT_PROFILE` 只能放虛構資料；`design/` 的截圖也會被部署，放進去前確認沒有真實帳號或個資。
- 改完用瀏覽器實際開啟：兩頁各看電腦與手機寬度，把次專科選幾個、搜尋、移除、儲存後到另一頁確認資料有帶過去，並檢查 console 無錯誤。
