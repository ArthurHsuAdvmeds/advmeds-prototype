## 4. 後臺備註分頁（新增）

使用者定的：

- **列表只顯示三項：備註內容／備註人／最後更新時間**（原本還有備註狀態，後來要求從列表拿掉）。
- **點一列（按鈕以外的地方）等於按「檢視」。**
- **檢視顯示四項：備註內容／備註人／備註時間／最後更新時間**（原本還有備註狀態，後來整個拿掉，資料也不再存狀態）。
- **新增／編輯照正式系統的「新增／編輯個案追蹤紀錄」，但拿掉「共照群組」「套用個管片語」（連同「個管追蹤樣板」鈕）、「狀態」（連同旁邊的編輯圖示）與「更新標籤」；正式系統的「狀態時間」在備註裡叫「備註時間」。**
- **內容的換行：新增／編輯按 Enter 換行；列表照正式系統把換行顯示成空白、排成一段（使用者附了正式系統的截圖），只有檢視照原樣換行。**
- **不管前臺或後臺，都只能編輯、移除自己建立的備註**；別人的備註只能檢視。
- **前臺與後臺的備註是同一份資料。**

畫面：

- 上方「共 N 則備註」＋「新增」；下方表格：備註內容｜備註人｜最後更新時間｜按鈕。
  每一列都有「檢視」，自己建立的另外有「編輯」「移除」；按鈕靠左排，別人的備註只有「檢視」也會跟其他列的「檢視」對齊。
  游標在列上變手指、整列變淺灰（`--row-hover`，只在有滑鼠的裝置）。
- **檢視備註**：照「檢視個案追蹤紀錄」，灰色標籤＋內容列出上面四項（正式系統是狀態後面接狀態時間，備註時間放在同樣位置）；右下「關閉」。
- **新增備註／編輯備註**：欄位由上而下是
  - 內容 *（文字框）
  - 備註時間 *（`YYYY/MM/DD HH:mm`，右側日曆鈕）

  底部右邊「取消」與「送出」（新增）／「儲存」（編輯），和正式系統一樣。

規則（原型自己定的部分）：

- 內容去掉頭尾空白後不能是空的（「請輸入內容」）；備註時間必填，而且要是存在的日期時間（「請輸入備註時間」／「備註時間的格式是 YYYY/MM/DD HH:mm」，2/30、25:00 都算錯）。錯誤時紅框＋紅字。
- 是不是自己建立的，用備註人跟目前登入的人（`CURRENT_USER`）比；後臺、前臺目前都是陳怡君登入，所以預設的「林志豪」那則在兩邊都只能檢視。
- 備註時間：新增時預設現在；可以直接打字，也可以按日曆鈕叫出瀏覽器內建的日期時間選擇器（藏起來的 `datetime-local`＋`showPicker()`，叫不出來時游標回到文字框）。
- 新增的排在最上面，備註人是目前登入的人（`CURRENT_USER`）；編輯改內容與備註時間，不改備註人與順序。存檔時「最後更新時間」設成現在。
- 點列開檢視：按到列上的「檢視」「編輯」「移除」就照按鈕做；在列上拖曳選字、放開時有選到字不算（是要複製文字）。列本身不進 `Tab` 順序，鍵盤用列上的「檢視」鈕。
- 移除前跳確認對話框（正式系統的樣子沒有提供，比照其他對話框）。
- 對話框：「取消」／「關閉」、點對話框外面、`Esc` 都會關閉；在文字框裡拖曳選字、放開時滑到外面不算點外面。
- 存檔、更新、移除後下方提示「已新增備註」「已更新備註」「已移除備註」；焦點放回「新增」或該則的「編輯」。
- 資料存 `sessionStorage`（鍵 `tsghb-commend:notes-v4`；欄位改過就換鍵名：v2 加了狀態、v3 狀態時間改成備註時間 `time`、v4 拿掉狀態）：重新整理還在，關掉分頁就回到預設的兩則（`DEFAULT_NOTES`）。
- 全部移除後顯示「還沒有備註，按「新增」寫下第一則。」
- 內容一律用 `textContent` 放進畫面，打 HTML 也只會當文字顯示。換行：列表先把 `\n` 換成空白再放進去（`white-space` 是一般的 `normal`，連續空白併成一個），
  不靠瀏覽器自己把換行變空白（照 CSS 規範，兩個中文字之間的換行可以直接拿掉、不留空白，各瀏覽器做法不一）；檢視用 `white-space: pre-wrap` 照原樣換行。存起來的內容保留原本的換行。
- ≤600px 改成一則一張卡片：內容；備註人、最後更新時間；按鈕，由上而下，不必左右滑才按得到；點卡片也是檢視。對話框在手機上內距 16、按鈕寬度跟著字。

### 查看個案備註（新增）

使用者定的：

- **「查看基本資料」下面新增「查看個案備註」，點開是對話框。**
- **對話框裡有「新增備註」，每一則備註一樣可以檢視詳情／編輯／移除（同後臺）。**
- **跟後臺是同一份資料；只能編輯、移除自己建立的備註**（見第 4 節）。

原型自己定的：

- 同一份資料的做法：同一個 sessionStorage 鍵（`tsghb-commend:notes-v4`）、同一組預設備註；每次打開對話框都重讀一次。
  在切換瀏覽頁裡前後臺切換時，看得到對方新增或改過的備註（同一個分頁才共用，分開兩個分頁開就各自一份）。
- 「查看個案備註」跟「查看基本資料」一樣是藍色文字連結，在它下面 8px。
- **個案備註對話框**：寬 720（其他對話框 640，疊上去時看得出後面還有一層）；標題「個案備註」；「共 N 則備註」＋右邊「新增備註」；
  下面是外框列表，每一則一格：內容（換行顯示成空白，同後臺列表）、灰色小字「備註人：…　最後更新時間：…」、右邊「檢視」（自己建立的另有「編輯」「移除」）；
  按鈕欄用 CSS subgrid 讓每一則共用同一欄，只有「檢視」的那幾則也會對齊；
  點這一則按鈕以外的地方等於「檢視」（拖曳選字不算）；備註多的時候只有列表在框內捲動；右下「關閉」。
- **檢視、新增／編輯、移除確認**都跟後臺一樣（欄位、檢查、送出／儲存），開在個案備註對話框上面，關掉後回到列表；`Esc` 只關最上面那一層。
- 顏色用個案資料卡的藍（`--teal-300`），不用緊急醫療通報的紅：備註跟著個案，不是跟著哪一種通報。
- 「已新增／已更新／已移除備註」的提示放在個案備註對話框裡面：對話框開著時，外面的東西會被遮罩蓋住、也不會被螢幕報讀軟體讀到。
- ≤760px：每一則改成內容、備註人與時間、按鈕由上而下；對話框內距 16、按鈕寬度跟著字。
