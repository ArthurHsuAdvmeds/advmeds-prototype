## 3. 分頁

- 四個分頁：歷次通報紀錄、對話留言區、通報史及處遇歷程、**備註（新增）**。

## 4. 備註分頁（新增）

使用者定的：

- **列表與檢視只顯示四項：備註內容／備註人／備註狀態／最後更新時間。**
- **新增／編輯照正式系統的「新增／編輯個案追蹤紀錄」，但不放「共照群組」。**

畫面：

- 上方「共 N 則備註」＋「新增」；下方表格：備註內容｜備註人｜備註狀態｜最後更新時間｜檢視、編輯、移除。
  備註狀態用和「通報歷程種類」一樣的彩色標籤，沒有狀態顯示「-」。
- **檢視備註**：照「檢視個案追蹤紀錄」，灰色標籤＋內容列出上面四項，狀態是名稱＋16px 色塊；右下「關閉」。
- **新增備註／編輯備註**：欄位由上而下是
  - 套用個管片語（下拉）＋「個管追蹤樣板」鈕
  - 內容 *（文字框）
  - 狀態（下拉，標籤旁有編輯圖示；選到的值顯示名稱＋色塊）
  - 狀態時間 *（`YYYY/MM/DD HH:mm`，右側日曆鈕）

  底部左邊「更新標籤」，右邊「取消」與「送出」（新增）／「儲存」（編輯），和正式系統一樣。

規則（原型自己定的部分）：

- 內容去掉頭尾空白後不能是空的（「請輸入內容」）；狀態時間必填，而且要是存在的日期時間（「請輸入狀態時間」／「狀態時間的格式是 YYYY/MM/DD HH:mm」，2/30、25:00 都算錯）。錯誤時紅框＋紅字。
- 套用個管片語：選了就接在內容後面（原本有字就換一行再接），選單回到「請選擇」，同一句可以再套一次。片語是虛構的（`PHRASES`）。
- 狀態的選項先沿用通報歷程種類（「-」、完成指派、更新表單，見 `KINDS`）；原生下拉選單畫不出色塊，所以選單文字設成透明，選到的值用 `.status-face` 疊在上面顯示。
- 狀態時間：新增時預設現在；可以直接打字，也可以按日曆鈕叫出瀏覽器內建的日期時間選擇器（藏起來的 `datetime-local`＋`showPicker()`，叫不出來時游標回到文字框）。
- 新增的排在最上面，備註人是目前登入的人（`CURRENT_USER`）；編輯改內容、狀態、狀態時間，不改備註人與順序。存檔時「最後更新時間」設成現在。
- 狀態時間有存，但依使用者的要求不顯示在列表與檢視（見第 6 節）。
- 移除前跳確認對話框（正式系統的樣子沒有提供，比照其他對話框）。
- 對話框：「取消」／「關閉」、點對話框外面、`Esc` 都會關閉；在文字框裡拖曳選字、放開時滑到外面不算點外面。
- 存檔、更新、移除後下方提示「已新增備註」「已更新備註」「已移除備註」；焦點放回「新增」或該則的「編輯」。
- 資料存 `sessionStorage`（鍵 `tsghb-commend:notes-v2`；加了狀態欄位後換過鍵名）：重新整理還在，關掉分頁就回到預設的兩則（`DEFAULT_NOTES`）。
- 全部移除後顯示「還沒有備註，按「新增」寫下第一則。」
- 內容一律用 `textContent` 放進畫面，打 HTML 也只會當文字顯示；換行照原樣顯示。
- ≤600px 改成一則一張卡片：內容；備註人、狀態、最後更新時間；按鈕，由上而下，不必左右滑才按得到。對話框在手機上內距 16、按鈕寬度跟著字。

## 5. 靜態、沒有動作的部分

Header 的通知與選單、「編輯基本資料」、通報史的篩選（下拉選得動但不會篩選）與「新增」、表頭「通報歷程種類」旁的編輯圖示、通報史每一列的檢視／編輯／移除，
以及備註對話框裡的「個管追蹤樣板」「更新標籤」和「狀態」旁的編輯圖示。

## 6. 待確認（給了正式規則就改掉）

- **狀態時間**：表單裡有（使用者只要求拿掉共照群組），但列表與檢視不顯示（使用者指定只顯示四項）。要不要從表單拿掉，或改成顯示。
- 備註狀態的選項清單（目前沿用通報歷程種類：完成指派、更新表單）。
- 套用個管片語的內容與套用方式（目前接在內容後面）、「個管追蹤樣板」「更新標籤」在備註裡要不要保留。
- 誰看得到、誰可以編輯／移除（目前任何人都能改任何一則），要不要留編輯紀錄；字數上限（目前沒有）。
- 通報史每一列的檢視／編輯和上方「新增」目前沒有動作；要的話可以照同一套對話框做（含共照群組）。
- 截圖寬度下 Header 只有通知與選單；更寬的螢幕正式系統可能會出現主選單與使用者名稱，原型一律照截圖。
- 平板與手機版面（篩選改兩欄／單欄、通報史表格在框內左右滑、備註改卡片）是原型自己排的。

## 7. 修改須知

- 資料都在腳本開頭：`HISTORY`（通報史的列）、`DEFAULT_NOTES`（預設備註）、人名 `CASE_NAME`、`CURRENT_USER`。這個 repo 是公開的，只能放虛構資料；不要把參考截圖或截圖上的個資放進來。
- **`.tbl-box` 的 `position: relative` 不能拿掉**：表頭的 `.sr-only`（「操作」）是絕對定位，少了它會跑出捲動框，手機上整頁被撐寬、畫面縮小。
- 改完用瀏覽器開電腦（1528 寬）與手機（375）看，備註的檢視、新增（空白送出、時間打錯）、編輯、移除走一遍，並檢查 console 無錯誤。
